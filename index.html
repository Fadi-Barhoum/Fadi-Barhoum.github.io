01 ZeroXGovernment Bureaucracy Reduction Platform +
ASP.NET Core 8React 19TypeScriptSQL ServerEntity Framework Core

A bilingual (Arabic/English) platform built for the UAE Ministry of Industry and Advanced Technology, digitising how government services and internal processes are assessed, simplified, and measured before and after reduction.

  • UAE Pass Integration:National single sign-on via a custom OAuth 2.0 authorization code flow built to match the ministry's identity gateway
  • Multi-Axis Assessment:Services scored across five weighted evaluation axes with a matrix-based classification engine
  • Process Zeroing:Full organizational hierarchy from sector down to individual procedure steps, with automatic before/after reduction comparison
  • Bulk Import:Transactional Excel import that maps flat spreadsheets into a five-level hierarchy with rollback on conflict
  • Fully Bilingual:Arabic/English with complete RTL support across every screen
02 Impact7SSeven-Star Service Excellence Assessment Platform +
ASP.NET Core 8React 19TypeScriptSQL ServerEntity Framework CoreAzure OpenAI

An enterprise platform for organizational excellence assessment, deployed at UAE government and private sector entities to run the full evaluation cycle from questions and evidence through scoring, improvement planning and follow-up.

  • Maturity Scoring Engine:Multi-level weighted scoring across service channels and entity-level evidence, producing a 0–7 star rating
  • Hybrid Authentication:Enterprise LDAP/Active Directory unified with local accounts behind a single sign-in flow
  • Granular Permissions:Six roles scoped by service channel and center
  • Action Planning:Improvement tracking with priorities, follow-ups and Kanban task management
  • AI Assistant:Integrated Azure OpenAI assistant answering questions from the system's own data
  • Centers Management:Geolocation and interactive mapping for multi-site evaluation
  • Reporting:Arabic-capable PDF report generation
03 ImpactSPcxProcess, Service & Customer Experience Management +

  • Visio Import:Dependency-free in-browser .vsdx importer built without external libraries

A strategy-to-execution platform for government entities, connecting vision and objectives to KPIs, operational plans and verified performance reporting in one governed path.

  • KPI Formula Engine:Server-side expression evaluator supporting manual, formula-driven and external API data sources, with full audit capture of inputs

05 ImpactLSSoftware Licensing & Entitlement Platform +
ASP.NET Core 10React 19TypeScriptSQL ServerEntity Framework Core

An in-house platform that issues and governs license keys for the company's product suite, letting each client activate the systems they purchased with defined subscription terms and user limits.

  • Digitally Signed Licenses:Each license cryptographically signed and verifiable, so altered terms are rejected automatically
  • Offline Verification:Licensed systems validate entirely on their own, with no network call to a license server — essential for closed government networks
  • Entitlement Control:Per-client expiry dates and user limits enforced at the product level
  • Multi-Product:Governs four separate company products from one console
  • Integration Documentation:Full specification authored for consuming product teams
